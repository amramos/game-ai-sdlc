# Research

The literature behind the plugins' rules. **Nothing here ships:** a plugin installs only what's under
its own folder in `plugins/`. Each topic distils talks, articles and evidence from real projects into
a short set of rules; the shipped skill carries the rules and cites the topic page for the reasons.

| Topic | Result | Ships in |
|---|---|---|
| [Game interfaces](game-ui/README.md) | amramos' ten commandments for game interfaces | `game-ui` (planned) |

## Adding a topic

- **One folder per topic:** a `README.md` with the rules, their checks and sources, and a `notes.md`
  with the detail per source.
- **Paraphrase.** Never copy transcripts or articles into the repository; link every source, with
  timestamps for videos.
- **Weigh sources honestly** (a lecture isn't an opinion piece), and record where they disagree and
  how the owner ruled.
- **Keep the trail:** every shipped rule cites its section here.
